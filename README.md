# Geodev-Lab-project-
Which areas of Dakwa, Abuja are prone to flooding based on GIS-based spatial analysis?

Mapping Flood-Prone Areas in Dakwa, Abuja Using GIS

#Project Brief

why It Matters

Flooding can affect people, properties, roads, and other infrastructure. This project focuses on identifying areas in Dakwa, Abuja that are potentially prone to flooding using GIS and spatial data. The results will provide a visual representation of flood-prone areas and demonstrate how geospatial technology can support flood-risk assessment and planning.

Data I Need

- Digital Elevation Model (DEM)
- Satellite imagery
- Study-area boundary
- Rainfall data
- Drainage/waterway data

## Data Sources

1. DEM — Copernicus GLO-30: https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM
2. Satellite Imagery — Sentinel-2: https://dataspace.copernicus.eu/data-collections/copernicus-sentinel-missions/sentinel-2
3. Rainfall Data — CHIRPS: https://www.chc.ucsb.edu/data/chirps
4. Boundary & Map Data — OpenStreetMap: https://www.openstreetmap.org/

Methodology

The project will involve collecting and preparing the required spatial datasets, defining the Dakwa study area, and processing the data in QGIS. The DEM will be used to analyse elevation, slope, and drainage characteristics. Satellite imagery will be used to derive land-use/land-cover information. Relevant flood-related factors will then be reclassified and combined using GIS overlay analysis to produce a final flood-prone area map.

Tools I'll Use

QGIS — spatial data processing, analysis
GitHub — project documentation

What I'll Build

The main output will be a GIS-based flood-prone area map of Dakwa, Abuja. 
Limitations

The accuracy of the results will depend on the quality and resolution of the available datasets.
Different datasets may have different spatial resolutions and acquisition dates.
Rainfall data may not completely represent local variations within Dakwa.
 The final map will indicate potential flood-prone areas and may not capture every actual flood event.
 Limited field validation may affect the level of accuracy of the results.
